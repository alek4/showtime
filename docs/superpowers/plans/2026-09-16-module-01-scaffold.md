# Module 1: Project Scaffold — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Bootstrap a running Next.js 15 app with Tailwind, Supabase clients, Vitest, and all design tokens wired — zero features, but the entire foundation every subsequent module builds on.

**Architecture:** Next.js 15 App Router, TypeScript strict, Tailwind with custom design tokens from DESIGN.md. Supabase clients split into server (uses `@supabase/ssr` + cookies) and browser (uses `createBrowserClient`). Vitest with jsdom for unit tests.

**Tech Stack:** Next.js 15, Tailwind CSS 3, @supabase/ssr, Vitest 1, @testing-library/react, next/font/google

**Spec:** `docs/superpowers/specs/2026-09-16-showtime-design.md`
**Design:** `DESIGN.md`
**Conventions:** `CLAUDE.md`

## Global Constraints

- TypeScript everywhere — no `any`, use `unknown` and narrow
- No `"use client"` unless component needs `useState`, `useEffect`, or browser event handlers
- All third-party API keys server-side only — never `NEXT_PUBLIC_` for secrets
- Fonts: Bebas Neue (display/`--font-bebas`), Outfit (body/`--font-outfit`), DM Serif Display italic (accent/`--font-dm-serif`)
- Colors: warm blacks, amber `#F5A623` accent, crimson `#C0392B` for watched state only
- No co-author lines in git commits
- TDD: failing test → implement → green → commit

- [x] **Step 5: Create lib/supabase/server.ts**

This file uses `next/headers` which is Next.js-specific and not testable in Vitest without heavy mocking. Create it without a test — its correctness is verified in Module 3 (Auth) via real sign-in flow.

```typescript
import { createServerClient } from '@supabase/ssr'
import { cookies } from 'next/headers'

export async function createClient() {
  const cookieStore = await cookies()

  return createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return cookieStore.getAll()
        },
        setAll(cookiesToSet) {
          try {
            cookiesToSet.forEach(({ name, value, options }) =>
              cookieStore.set(name, value, options)
            )
          } catch {
            // Server Component context — cookies can only be set in middleware or Route Handlers
          }
        },
      },
    }
  )
}
```
